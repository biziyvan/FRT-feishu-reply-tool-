========================================
  飞书自动回复助手 · 使用说明
========================================

【这是什么】
一个自动帮你回复飞书「AI教学平台」教学机器人的小工具。
它会自动监测机器人发来的题目，用大模型生成答案并发送。

----------------------------------------
一、快速开始（3 步）
----------------------------------------

  第 1 步：双击「飞书自动回复助手.exe」

  第 2 步：首次运行会弹出配置窗口，填 3 项：
         ① 飞书网页版地址
            —— 打开飞书网页版，从浏览器地址栏复制完整地址，
               形如 https://xxxxxx.feishu.cn/next/messenger/
         ② 机器人的会话名称
            —— 飞书左侧列表里那个机器人的名字，如「AI教学平台」
         ③ 大模型 API Key
            —— 用于生成答案的密钥（硅基流动 / DeepSeek 等都可以）

         填好后可点「测试连通性」验证密钥是否有效，
         然后点「保存并开始」。

  第 3 步：点「启动监控」。
         首次会打开一个浏览器窗口，请用手机飞书 App 扫码登录。
         登录一次即可，以后不用再登。

----------------------------------------
二、日常使用
----------------------------------------

  · 双击 exe → 点「启动监控」→ 保持程序运行即可
  · 浏览器窗口可以最小化，但**不要关闭**
  · 程序窗口下方的日志区会实时显示每一条回复
  · 想停就点「停止」按钮

  ★ 看到「[待命] 暂无新题，持续监控中…」是正常的，
    说明已答完当前题目，正在等机器人出下一题。

----------------------------------------
三、常见问题
----------------------------------------

  Q：双击没反应 / 闪一下就没了？
  A：可能是被杀毒软件拦截（PyInstaller 打包的程序常被误报）。
     把整个文件夹加入杀毒软件白名单，再重新双击。

  Q：提示找不到浏览器？
  A：本程序使用你电脑上的 Microsoft Edge。
     Win10 / Win11 都自带 Edge，一般无需额外安装。
     若确实没有，请到微软官网免费下载 Edge。

  Q：浏览器被别的窗口盖住了还工作吗？
  A：可以的，程序做了专门处理。但**不要关闭**浏览器窗口。

  Q：能放到别的盘或 U 盘吗？
  A：可以。整个文件夹一起移动即可（必须是整个文件夹，不能只拷 exe）。
     数据都会保存在这个文件夹里。

  Q：换电脑了怎么办？
  A：把整个文件夹拷过去即可；但登录态可能需要重新扫码。
     注意 config.yaml 里有你的 API Key，别随意分享。

  Q：日志里出现"浏览器启动失败"？
  A：程序已自动重试 5 次并尝试自我修复（清理锁文件、结束残留
     浏览器进程）。若最终仍失败，日志里会给出处理步骤，按顺序做：
       ① 关闭所有 Edge 窗口，点「启动监控」重试
       ② 仍失败 → 删除本目录下的 .browser_data 文件夹再启动
          （需重新扫码登录）
       ③ 仍失败 → 重启电脑后重试
     最常见的原因有两个：上次程序被强制结束，浏览器没退干净；
     或者 Edge 正在后台自动更新——等 1 分钟再点启动通常就好了。

  Q：启动后浏览器停在登录页不动了？
  A：这是首次运行的正常现象，需要你扫码登录飞书。
     用手机飞书 App 扫一下浏览器里的二维码即可，登录一次长期有效。
     日志会显示"需要登录，请扫码（最多等 3 分钟）"。

  Q：能开两个程序窗口吗？
  A：不能。程序会拦住第二次启动并提示"程序已在运行"。
     两个窗口会争抢同一个浏览器，必然有一个失败。

  Q：点了按钮没有任何反应？
  A：程序对每一步操作都会给出提示框。若真的毫无反应，
     请打开本目录下的 launcher_error.log，里面记录了详细错误，
     把该文件内容发给技术支持即可定位问题。

  Q：提示"保存失败"？
  A：说明当前目录不可写。请把整个文件夹移到自己的文档、
     桌面或 D 盘等可写位置（不要放在 C:\Program Files 下）。

  Q：回复重复了 / 答非所问？
  A：先看日志。若持续异常，点「停止」再「启动」重启一次。

  Q：写代码的题会怎么回答？
  A：给极简的核心代码，代码里不写注释，也不写异常处理、参数校验、
     多余函数这类"太完善"的东西，代码块后面用一句话说明关键行的作用。
     （机器人对代码题要求"说明关键行的作用"，这句不能省。）
     想让回答更详细或更简，可编辑同目录 config.yaml 里
     llm.system_prompt 的【代码题】段，改完重启程序生效。

  Q：想换模型或改配置？
  A：点「修改配置」重新填写，或直接编辑同目录下的 config.yaml。
     ★ 注意：编辑 config.yaml 后必须重启程序才会生效。

  Q：程序卡住 / 浏览器被锁住？
  A：按 Ctrl+Shift+Esc 打开任务管理器，
     结束所有 msedge.exe 和「飞书自动回复助手」进程后重启。
     （点「停止」按钮会连带关闭浏览器整棵进程，一般不会有残留。）

  Q：怎么更新历史对话（换课程后）？
  A：程序会自己读最新消息。如需重建历史，可删除 history.json 后重启。

----------------------------------------
四、文件说明
----------------------------------------

  飞书自动回复助手.exe   ← 主程序，双击它
  _internal\             ← 程序运行库（勿删除、勿改动）
  使用说明.txt           ← 本文件
  config.yaml            ← 你的配置（首次配置后自动生成，含 API Key）
  config.example.yaml    ← 配置模板
  .browser_data\         ← 浏览器登录态（扫码后生成）
  auto_reply.log         ← 运行日志（历史）
  live.log               ← 实时日志（与界面下方显示的内容一致）
  launcher_error.log     ← 界面错误记录（排查问题用，正常时不存在）
  answered.json          ← 已答题目记录
  reply_stats.json       ← 问答统计

  ★ 移动或备份时，请整个文件夹一起操作。
